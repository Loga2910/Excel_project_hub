#  Railway Ticket Analysis Dashboard

##  Project Overview

The Railway Ticket Analysis Dashboard is an interactive Excel dashboard designed to analyze railway ticket revenue across different dimensions such as payment methods, coach types, age groups, and yearly trends.

This dashboard helps users identify revenue patterns, customer demographics, and preferred payment methods through dynamic visualizations and slicers.
